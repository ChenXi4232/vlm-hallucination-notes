## 状态约定

| 状态 | 含义 |
|---|---|
| 待读 | 仅登记来源，尚未形成结构化判断 |
| 速览 | 已提取核心问题和方法，但实验细节未完全核对 |
| 已精读 | 已覆盖方法、实验、局限、baseline 与研究启发 |
| 待复现 | 已精读并进入实现/实验队列 |
